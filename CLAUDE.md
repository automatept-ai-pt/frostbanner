# FrostBanner — правила работы для Claude Code

## О проекте
- Виджет баннера согласия на cookies (GDPR) для сайтов клиентов FrostBanner (frostbanner.com).
- Исходный код: `src/fb.js` (один файл, без зависимостей). Клиентам отдаётся собранный `dist/fb.min.js`.
- Репозиторий **публичный** на GitHub (лицензия MIT). Всё, что попадает в коммит, видят все.
- Хостинг-сервис, дашборд и API в этом репозитории не лежат.

## Общение
- Отвечай на русском. Английские термины при первом упоминании поясняй по-русски.
- Пиши коротко и по пунктам: что сделал, что проверить, какие есть риски.
- Риски и проблемы называй прямо, без смягчений.

## Git — строгие правила
- **Никогда не делай `git push` без явного разрешения** в текущем сообщении. Пушить только ветку `main`. **Никогда не используй `git push --all`** и `--mirror`.
- Никогда не переписывай историю, которая уже есть на `origin` (никаких `push --force`).
- Одна задача — один коммит с понятным сообщением на английском.
- Перед большой задачей проверь, что рабочее дерево чистое. Если нет — сначала спроси.
- **Не коммить:** локальные рабочие заметки (`IMPROVEMENTS.md`), папку `reports/`, описания ещё не исправленных уязвимостей, ключи, токены, пароли. Если такой файл появился — добавь его в `.gitignore`.
- Не удаляй файлы и ветки без подтверждения.

## Сборка
- После **любого** изменения `src/fb.js` пересобери `dist/fb.min.js`:
  `npx terser src/fb.js -c -m --comments '/^!/' -o dist/fb.min.js`
- Коммить `src/fb.js` и `dist/fb.min.js` вместе, в одном коммите.
- Версия записана в трёх местах: заголовок `src/fb.js` (строка 1), `FrostBanner.version` в `src/fb.js`, `dist/fb.min.js` (после пересборки). Меняй версию только по команде, во всех местах сразу.

## Как завершать задачу
1. Сделай изменение, пересобери `dist`, если трогал `src/fb.js`.
2. **Независимая проверка:** запусти отдельного агента-проверяющего, который не видел, как писался код. Он проверяет последний коммит или diff на баги, безопасность (XSS, внедрение кода) и соответствие GDPR и пишет вердикт. Найденные проблемы исправь до слова «готово».
3. Закоммить (без push).
4. Запиши отчёт в `reports/ГГГГ-ММ-ДД-кратко-о-задаче.md`:
   - что сделал и зачем;
   - какие файлы изменил, хеш коммита;
   - вердикт проверяющего агента;
   - как проверить вручную;
   - что осталось или вызывает сомнения.
5. В чате дай короткое резюме (3–5 пунктов) и путь к отчёту.

## Безопасность и GDPR
- До согласия посетителя никакие скрипты и iframe категорий, кроме `necessary`, не должны выполняться или загружаться.
- Любое значение из конфига, которое попадает в HTML или CSS, проверяй и экранируй.
- Не делай задачи вне папки этого репозитория.
