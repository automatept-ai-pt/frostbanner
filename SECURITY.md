# Security policy

If you find a security issue in the FrostBanner widget or service, please report it privately to **support@frostbanner.com** with the subject "Security". Include the steps to reproduce and, if possible, a proof of concept.

Please do not open a public issue or disclose the problem before we have had a reasonable chance to fix it. We reply within a few working days.

Thank you for helping keep FrostBanner and its users safe.
